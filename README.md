# 东方艾比特 ~ IBIT in BIT

## 创作者

## 户籍

源代码另见<https://github.com/usamidi/DanmakuGame/>

## 简介

「东方艾比特　～ IBIT in BIT」为机器人弹幕射击游戏（STG）

本作品是使顽固僵化了的游戏创作大脑变得升级起来的，训练作者大脑这种类型的游戏（多半是假的）

- ＊本游戏包含过激的弹幕场景
  　　请小孩子，或者弹幕过敏症患者与校医院联系。

在不知何时起到处都是区的北食堂附近，食堂大爷们的弹幕苏醒了。

## 故事背景

　　北食堂。位于BIT北侧界线上的一个寂静的食堂。
　　忘记回家的学生们仿佛把这里当成了自己的寝室一般，一直以来这里都因
　为人类以外的区而无比地热闹。
　　充满区的北食堂自然不会有人类的参拜客到访，食堂内的大爷因为信仰心
　的不足而烦恼。

　　即便那样的食堂也会有转机到访。

　　北理工的机器人，艾比特，正烦恼着。

　　　艾比特　「怎么样才能把区们赶回去啊。
　　　　　　　怎么样才能收集同学的信仰啊」

　　　？？？「噢。好像很好吃的盖饭嘛」

　　　艾比特　「啊，数智学伴。
　　　　　　　嗯」

　　　数智学伴 「烦心事吗？」

　　　艾比特　「前不久，出现个有点奇怪的访客」

　　　数智学伴「这个食堂啊，不净是些奇怪的访客吗」

　　对于学生而言信仰心就是他们的力量。

　　缺少食客的北食堂，其力量逐渐衰退，现在已经跌落到在
　那据说八百万区参与的会谈中其意见被大家无视的地步。

　　即使说BIT中的食堂仅此一家（迫真），但不可否认和外面世界中拥
　有若干食堂的厨师相比其拥有的信仰心的不足，北食堂的地位
　正一个劲儿地下降。

> 云上充满了光芒。
>
> 远处能听见机械传来的声音。是保安醒来了吗。
> 这里是学校的学生所无法踏入的世界。
> 树木建造的房屋。
> 不合时令的蛙鸣声。数不清的区蜕皮后的空壳。
>
> 它就在那里。一直呆在这个地方。
> 和一个故障机器人一起。
